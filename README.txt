# Undangan DWIPANTARA 2026

Alur:
1. Amplop tertutup.
2. Klik amplop.
3. Amplop berubah ke versi transparan terbuka dengan kertas putih.
4. Halaman INVITATION melompat keluar dari posisi kertas di dalam amplop.
5. Kertas membesar memenuhi layar.
6. Setelah itu halaman web berisi INVITATION lalu INFO.

Nama acara: DWIPANTARA 2026.
